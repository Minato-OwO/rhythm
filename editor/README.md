# FOUR FLOW Editor

既存のGimmick Editorのフォルダ読み込み・プロパティ・レイヤー式タイムラインを、FOUR FLOWの4レーン譜面と演出に合わせて改修しています。
別の`gimmick.json`は作らず、ノーツと演出をゲームがそのまま読み込める`chart.json`に保存します。

## 開く

プロジェクト直下で`npm start`を実行し、`http://localhost:5173/editor/`を開きます。
ゲームのサーバーを起動し直すと、このエディタの配信設定が反映されます。
この方法ではエディタのビルド・追加インストールは不要です。3D描画用A-Frameはゲームと同じCDNを使用します。

「曲フォルダを開く」で`songs/曲名/`を選ぶか、フォルダを中央へドロップします。
フォルダ内の`chart.json`、その`audio`で指定した音声、フォルダ内のGLBを読み込みます。GLBはサブフォルダ内も対象です。
「ゲームの曲」から開く場合は一覧を選び、右の「開く」を押してください。「更新」で一覧を再取得します。
音声がない場合も譜面は編集できます。新しい曲は「新規」→「音声を選ぶ」から作成できます。

## 編集

タイムラインの上4段はD/F/J/Kのノーツ、その下に全体SVと、レーン・画面・背景の各種演出があります。
空白をダブルクリックすると、そのレーン・演出の項目を追加します。上部の「＋ノーツ」「＋演出」でも追加できます。
項目を選ぶと、右のプロパティに時刻・レーン・演出のパラメーターを表示します。
曲情報の「選曲画面に『点滅注意』を表示」で、この難易度だけに注意表示を付けられます。補足文は任意です。JSONには `flashWarning`（true/false）と `flashWarningText`（補足文）として保存します。

- ドラッグ：開始位置を移動。ノーツは別のノーツ段へ動かすとレーンも変わります。
- 演出ブロックの左右端：開始・終了位置を変更します。
- ノーツ種類でLNを選ぶと、初期長さ1拍のLNを追加します。選択項目の「種類」でもタップ/LNを切り替えられます。
- LNは右側の終点入力、またはタイムラインの左右端で長さを調整します。本体と同じSVで胴・終点を描画します。
- ノーツを選び、右側の「個別SV倍率」でそのノーツだけの速度を設定できます。1で全体SVと同じ、0.5で半速、2で倍速です。タップ・LN両方に対応し、LNは始点・胴・終点へ同じ倍率を使います。
- 個別SVは全体SVに掛け合わせます。全体SVが0.5、個別SVが2なら実効倍率は1です。音源・判定時刻は変わりません。
- 個別SVは−1,000,000〜＋1,000,000の有限値です。全体SVと範囲SVの開始・終了倍率も同じ上限です。0は通常の接近時間から判定線上に固定し、負数は移動方向を反転します。1以外のノーツにはタイムライン上で黄色の下線を付け、マウスを重ねると倍率を表示します。
- 「＋全体SV」または全体SV段のダブルクリックで全ノーツの速度変更を追加します。倍率1で通常、0で停止、負数で逆走します。次のSVまで有効です。
- 全体SVを選び、「SVの種類」を「範囲で変化」にすると、開始倍率・終了倍率・変化の長さ・変化の仕方を設定できます。例：開始−9、終了1、長さ4拍、「なめらか」。
- 範囲SVの長さは拍数または秒数で指定できます。拍数ならBPM変更に追従し、秒数なら実時間を保持します。タイムラインの帯に「×−9 → ×1」を表示し、両端のドラッグで範囲を調整できます。
- 範囲の終了後は終了倍率を保持します。途中で別のSVが始まる場合は後から始まるSVが優先され、元の範囲SVには戻りません。「固定倍率」へ戻すと従来の時刻指定SVとして使えます。
- 範囲の終了から次の固定SVまでの空白は、終了倍率を一定で保持します。次の固定SVに向けた補間は行わず、その時刻で即座に切り替えます。タイムライン上部の「SV ×倍率」で現在の値を確認できます。
- 演出の「標準ステージ」から、床グリッド・アーチをまとめて、または個別に調整できます。不透明度0でフェードアウト、1で再表示、途中の値で半透明にします。
- 標準ステージの「変化にかける時間」でフェード時間を指定します。0秒で即時切替でき、「変化の仕方」は一定・なめらかから選べます。変更後は次の標準ステージ演出まで状態を保持します。
- 「元の色を使用する」を外すと、標準ステージへ着色できます。元の色へ戻す場合は、次の標準ステージ演出でチェックを入れます。
- 標準ステージ演出を置いた対象は、背景GLB・JSの自動非表示より優先されます。シーク・ポーズ・リトライに対応し、ゲームと同じ表示になります。サンプルは `examples/default-stage/chart.json` です。
- Shift / Altを押しながらドラッグ：スナップを解除します。
- 時刻は0始まりの拍、または音源先頭からの秒数です。読み込んだ項目の指定方法を保持します。
- BPM・オフセットを変えると、拍指定の項目が追従します。秒数指定の項目は固定です。
- 終了時刻はノーツ・演出が収まる長さまで自動延長します。
- 同じレーンの同時刻ノーツや不正な演出値はエラーとして表示します。
- 色変更が重なる場合や画面演出が重なる場合も、本体と同じ処理でプレビューします。

再生は音声と3Dプレビューを同期し、プレビュー内のノーツは自動演奏します。
タイムラインの空白・目盛りをクリックするとシークします。停止中でもその時点の演出を描画します。
プレビュー背景のドラッグで視点を見回せます。
プレビューのノーツ位置とタイムライン上部のSV倍率は、同じ親画面の再生時計を参照します。プレビュー側では別の時計による時刻の外挿やSV値の補間を追加しません。
プレビューはLNも自動演奏し、停止中のシークでも途中まで押した状態を再構成します。
本体と同じ濃く太いLNを表示し、終点100ms前で保持完了になります。終点で離す精度判定はありません。
「背景シーン(JS)」はゲームと同じ背景モジュールを使用します。Neon Circuitの氷と時計のシーンは「ゲームの曲」から読み込めます。
背景JSの相対パスはサーバー上の譜面JSONを基準に解決します。JS素材は保存時に自動コピーしないため、別曲へ移す場合は背景用フォルダもコピーしてください。

## OSZ・OSUの読み込み

「OSZ / OSU読込」からOSZを1つ選びます。複数の4K譜面があれば難易度を選択します。
OSU単体を選ぶ場合は音声も一緒に選ぶか、後から「音声を選ぶ」で指定してください。
chart.jsonのない展開済みフォルダは「曲フォルダを開く」またはドロップで変換できます。
対象はosu!maniaの4Kで、SV・LNを保持します。
音声はそのまま使用し、元のファイルは変更しません。
「フォルダへ保存」でJSONと音声を保存します。エディタ上でSV・LN・背景演出を追加編集できます。
JSON保存だけの場合、音声ファイルは別途曲フォルダへ配置してください。
ストーリーボード・動画・カスタムヒットサウンドは取り込みません。
元のBPM変化はノーツの絶対時刻とSVに反映し、元データもosu内へ保存します。拍目盛・拍入力・メトロノームは基準BPMを使います。
一括変換用のコマンドとJSONの書式はプロジェクト直下のREADME.mdを参照してください。

「GLBを追加」で背景用のファイルを読み込み、「背景GLB」の段をダブルクリックして表示区間を作ります。
曲フォルダやゲームの曲から開いた場合は、そのフォルダにあるGLBを右側の選択欄で選べます。
開始時刻・長さ・不透明度・色・位置・向き・倍率・回転速度・フェードを編集できます。
位置はレーン中央の床を基準にしたメートル、回転は度です。
基準サイズはモデルの最長辺を揃える寸法で、0なら元の寸法を使います。
アニメーションは`auto`で最初の動作、`none`で停止、名前指定で該当する動作を使います。
「非表示」のイベントを置くと、その区間だけGLBを隠します。
GLB同士が重なる区間は後から始まったイベントを優先し、終了すると前のイベントが継続中なら戻ります。
星も重なった区間では後から始まるイベントを使用し、背景パルスは加算します。
GLBは再生前に読み込みを待ちます。停止中のシークでもモデルの回転・動作・フェードがその時刻に追従します。

サンプル曲では`night_sky_visible_spectrum_monochromatic.glb`を8拍目（3.75秒）から40秒間表示します。
サンプルの基準サイズは100m、中心位置は`[0, 1.65, -20]`です。位置や大きさは右側で変更できます。

| キー | 操作 |
| --- | --- |
| Space | 再生・一時停止 |
| D / F / J / K | 現在位置へ各レーンのノーツを追加 |
| ← / → | スナップ間隔でシーク |
| Delete / Backspace | 選択項目を削除 |
| Ctrl / Cmd + D | 選択項目を次のスナップ位置へ複製 |
| Ctrl / Cmd + Z | 元に戻す |
| Ctrl / Cmd + Y、Ctrl / Cmd + Shift + Z | やり直す |
| Ctrl / Cmd + S | フォルダへ保存 |
| Ctrl / Cmd + Shift + S | JSONをダウンロード |

文字や数値の入力欄にフォーカスがある間は、保存以外の編集用ショートカットを実行しません。
マウスで選択肢・ボタン・チェックボックス・スライダーを操作した後は、クリックし直さずに編集ショートカットを使えます。
文字・数値はEnterで確定してショートカットへ戻れます。Escapeでも入力欄からフォーカスを外せます。Tabで移動した選択肢は、キーボードによる選択操作を続けられます。
タイムラインの高さは境界のドラッグで、表示倍率は＋・−で調整できます。
拍スナップの縦ラインと上部の目盛りは、1/1拍＝白、1/2拍＝赤、1/3拍＝紫、1/4拍＝青、1/8拍＝黄で表示します。
たとえば1/8拍を選んでも、整数拍は白、半拍は赤、1/4拍の位置は青を優先します。色はスナップの選択肢でも確認できます。
ラインは曲のBPM・オフセットに揃え、縮小時は細かい区切りから省きます。msスナップでは音源先頭を基準にした共通色のラインを表示します。
各ラインは拍の絶対位置へ直接描き、画面内とその前後だけを生成します。繰り返し背景の端数幅による位置ずれを避け、スクロール・ズーム後も上部の目盛りと同じ位置に揃えます。

## 保存

「フォルダへ保存」で曲のフォルダを指定します。保存時にブラウザーの書き込み許可が必要です。
フォルダ読み込みで開いた場合は同じフォルダへ保存し、ゲーム一覧やドロップから開いた場合は保存先を選びます。
音声・GLBを新しく選んだ場合や別のフォルダへ保存する場合は、それらの素材も一緒にコピーします。
JSONには曲フォルダからの相対パスを保存し、プレビュー専用の一時URLは書き出しません。
個別SVは各ノーツの `scrollMultiplier`、全体SVは `scrollVelocities` に保存します。省略した個別SVは1として扱い、複製・元に戻す・やり直すでも保持します。
範囲SVは `multiplier`（開始倍率）、`endMultiplier`（終了倍率）、`durationBeats` または `durationSeconds`（長さ）、`easing`（`linear` または `smoothstep`）を保存します。サンプルは `examples/sv-range/chart.json` です。
保存時は `mode` で `constant`・`range` を区別し、固定倍率からは範囲用の長さ・終了倍率・補間方法を取り除きます。従来の `mode` がないJSONも引き続き読み込めます。
保存先を`songs/曲名/`にすると、ゲーム側の「選曲 → 一覧を更新」で利用できます。編集した曲を選び直すと再読み込みします。

フォルダへの直接保存が使えないブラウザーでは「JSON保存」を使い、ダウンロードした`chart.json`を音声・GLBと同じ曲フォルダへ置いてください。JSON保存に素材自体は含まれません。
ノーツが空の編集中データはプレビューできますが、ゲーム用に保存するには1個以上のノーツが必要です。
読み込んだ音声ファイル名・拍指定と秒数指定・曲の追加メタデータを保持し、エディタ内部のIDは書き出しません。

## Viteで開発する場合

`editor`内で`npm run dev`を実行すると、通常は`http://localhost:5174/`で開きます。
ゲームの曲一覧を使う場合は、プロジェクト直下のゲームサーバーも5173番で起動してください。
共有のゲーム描画ソースは親フォルダから参照し、`/api`と`/songs`は5173番へ転送します。
ビルドする場合のエントリーは`index.html`と`preview.html`の2ページです。
既存の`dist`は今回ビルドしていません。ゲームサーバーの`/editor/`は更新済みソースを配信します。

依頼に合わせてコードのみを変更しています。ビルド・実行・画面確認は行っていません。
